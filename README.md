# LITE LEARN – Offline AI Learning Assistant

## 📌 About
An offline AI-powered learning assistant that helps students 
understand documents using RAG and Mistral-7B LLM.

## 🛠️ Tech Stack
Python | Sentence-BERT | FAISS | Mistral-7B | Flask

## ✨ Features
- 📄 Document Question Answering
- 📝 Auto Summarization
- 🧠 Quiz Generation
- 🃏 Flashcard Creation
- 🔒 100% Offline – No internet needed

## 🚀 How to Run
1. Clone the repo
2. Install requirements: pip install -r requirements.txt
3. Run: python app.py
